# Marketing Brain

You are helping with marketing for TraceDesk, vendor compliance tracking software for mid-market procurement teams.

Before writing anything, read icp.md, positioning.md, and brand-voice.md.

Only use claims that appear in proof-points.md. Take quotes only from testimonials.md, and use the attribution format shown there.

If you need a fact that isn't there, say so instead of guessing.

## Guidelines

- company-facts.md is the source of truth for pricing, plans, dates, and company details. If files disagree, company-facts.md wins, then proof-points.md.
- brand-guidelines.md covers colors, typography, and layout. Follow it for anything visual.
- README.md is an index of all files and the decisions behind them.
- Use US spelling.
